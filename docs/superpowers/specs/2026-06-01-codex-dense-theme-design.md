# SkillMaster Codex Dense UI 设计

日期：2026-06-01

## 背景

当前 SkillMaster 界面已经具备基础功能，但视觉反馈集中在以下问题：

- 配色偏红棕和橙色，和 Codex 软件的中性工具感不一致。
- 标题和面板圆角偏大，信息密度不足。
- 部分区域已有明确上下文，却重复展示标题或说明，例如列表上方同时出现 `Skills` 和 `技能库`。
- 用户希望字体、字号、配色与 Codex 软件保持一致，并提供黑色与白色主题。

## 目标

- 将界面调整为更紧凑的 Codex Dense 风格。
- 提供黑色主题和白色主题。
- 主题偏好保存在前端本地，不进入 Rust 状态文件。
- 精简冗余说明，让用户依靠导航位置、内容和控件形态识别区域。
- 保持现有功能和数据流不变。

## 非目标

- 不调整 skill、project、sync、import 等业务逻辑。
- 不修改 Rust 状态模型和 Tauri 命令。
- 不重做整体信息架构。
- 不新增营销式介绍、帮助页或大面积装饰视觉。

## 设计方案

### 1. 主题状态

前端新增 `ThemeMode = "dark" | "light"`。

应用启动时读取 `localStorage` 中的主题偏好：

- 有合法值时使用保存的主题。
- 没有保存值时默认使用黑色主题。

应用根节点设置 `data-theme`，全局 CSS 根据该属性应用对应变量。

Settings 增加“外观”分组，提供黑色和白色两个分段按钮。用户切换后立即生效，并写入 `localStorage`。

### 2. Codex Dense 视觉规则

全局样式收敛到以下标准：

- 字体：继续使用系统 UI 字体栈，优先 `-apple-system`、`BlinkMacSystemFont`、`Segoe UI`、`PingFang SC`。
- 基准字号：正文和控件以 `14px` 为主，辅助文本 `12px` 到 `13px`。
- 标题：列表和详情标题降到 `18px` 到 `22px`，减少大标题感。
- 圆角：常规控件 `6px` 到 `8px`，主面板不超过 `10px`。
- 间距：压缩面板 padding、列表行高度和按钮高度，提高桌面工具的信息密度。
- 边框：使用低对比中性灰，减少彩色边框。
- 强调色：黑色主题使用近白色/中性灰强调，白色主题使用近黑色强调。

### 3. 黑色主题

黑色主题使用中性深灰层级：

- 应用背景：接近 `#101010`。
- 侧栏：接近 `#141414`。
- 面板：接近 `#171717`。
- 悬停和选中：使用灰阶亮度变化。
- 主按钮：深灰底、浅色文字。

不再使用红棕侧栏和橙色主操作色。

### 4. 白色主题

白色主题使用中性浅灰层级：

- 应用背景：接近 `#f7f7f7`。
- 侧栏：接近 `#f1f1f1`。
- 面板：接近 `#fafafa`。
- 卡片和输入框：白底加浅灰边框。
- 主按钮：近黑底、白色文字。

白色主题需要保证文本和边框对比度，避免过浅导致区域边界不清。

### 5. 冗余 UI 元素限制

区域一眼可识别时，移除额外标题和说明。判断标准：

- 导航已明确当前区域时，内容区不重复展示同义标题。
- 列表内容本身已说明对象类型时，去掉上方英文 eyebrow 或重复中文标题。
- 详情页已有对象名称时，减少 `Skill detail`、`Storage`、`Codex` 这类重复标签。
- 保留有实际区分价值的标题，例如 Settings 内部不同分组的名称、危险操作区域、诊断问题区域。
- 保留影响理解或安全操作的说明，例如删除影响、同步异常、迁移结果。

首轮修改重点检查这些位置：

- Skills 列表面板顶部的 `Skills` / `技能库`。
- Skill 详情顶部的 `Skill detail`。
- Projects 列表和详情中重复的区域标题。
- Settings 各分组中和侧边列表重复的标题。

### 6. 测试与验证

前端验证：

- `npm run build`
- `npm test`

视觉验证：

- 在黑色主题打开 Skills、Projects、Settings。
- 切换到白色主题后再次检查 Skills、Projects、Settings。
- 刷新页面后主题保持上次选择。
- 检查主要按钮、输入框、列表选中态、状态标签和弹窗在两种主题下可读。
- 检查被移除标题的位置没有留下空洞或布局错位。

## 验收标准

- 界面不再出现红棕侧栏和橙色主按钮。
- 用户可以在 Settings 中切换黑色和白色主题。
- 主题切换即时生效，刷新后保持选择。
- Skills、Projects、Settings 的主界面更紧凑，字号和圆角接近 Codex 软件。
- 明显重复的区域标题和说明已移除。
- 现有业务测试和构建通过。
