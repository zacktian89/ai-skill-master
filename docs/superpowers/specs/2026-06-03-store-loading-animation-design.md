# SkillMaster 商店页加载动画设计

日期：2026-06-03

## 背景

当前商店页在加载排行榜或搜索结果时，左侧列表区域没有明确的内容级加载反馈，只有搜索按钮上的小型转圈图标。

用户希望在商店页加载中时，在列表内部展示一个基于当前 logo 的加载动画，并使用 Lottie 组织动画表现。后续还希望这个加载动画能力可以被其他页面复用。

## 目标

- 为商店页提供更清晰的首次加载反馈。
- 加载反馈展示在左侧列表内容区内部，不遮挡搜索栏和榜单切换控件。
- 动画基于当前 SkillMaster logo 设计，使用 Lottie 播放。
- 加载组件做成通用能力，后续其他页面可以直接复用。
- 在动画下方补充轻量骨架屏，增强“列表即将出现”的感知。

## 非目标

- 不修改商店数据请求方式、接口参数或缓存策略。
- 不改变右侧详情面板的加载逻辑。
- 不为每一次搜索和榜单切换都展示大加载态。
- 不引入复杂的全局 loading 管理器。

## 设计方案

### 1. 通用加载组件

新增通用组件，建议命名为 `src/components/AppLoadingAnimation.vue`。

组件职责：

- 播放一个基于当前 logo 的 Lottie 动画。
- 按需展示骨架屏。
- 通过 props 控制尺寸、骨架条数和场景样式，保持复用性。

建议 props 范围保持最小：

- `size?: "sm" | "md" | "lg"`，控制 logo 动画尺寸。
- `showSkeleton?: boolean`，控制是否显示骨架屏。
- `skeletonRows?: number`，控制骨架条数，默认 3。
- `variant?: "panel" | "inline"`，控制容器间距和布局。

本次实现只使用当前需求所需的最小集合，不提前加入文案、进度值、状态切换等额外能力。

### 2. Lottie 动画表现

动画素材基于当前品牌 logo，优先使用现有资源视觉做法，保持与侧边栏品牌图一致。

动画效果控制在轻量范围：

- 主体做缓慢缩放呼吸。
- 叠加轻微旋转或上下浮动。
- 配合透明度节奏变化。
- 可加入一层低对比光晕，增强加载感。

动画应循环播放，节奏平稳，不做跳跃式强刺激效果。

资源组织建议：

- Lottie JSON 单独放在前端资源目录，例如 `src/assets/lottie/skillmaster-loading.json`。
- 组件内部直接消费本地 JSON。

如果当前项目尚未接入 Lottie 播放库，本次只引入一个最小依赖，不扩展更多动画基础设施。

### 3. 骨架屏设计

首次加载动画下方展示 3 到 4 条骨架列表项。

骨架屏规则：

- 形态参考当前商店列表行结构。
- 使用暗色主题下已有 token 的低对比背景和高光渐变。
- 行高、圆角、间距接近真实列表，避免出现完全不同的视觉语义。
- 骨架只作为辅助，不显示文字。

骨架由纯 CSS 实现，不进入 Lottie 动画素材。

### 4. 商店页接入规则

商店页新增一个“是否已经完成首次加载”的本地状态，建议命名为 `hasLoadedOnce`。

行为规则：

- 进入商店页并发起首次列表请求时：
  左侧列表内容区显示通用加载组件，配置为 `variant="panel"`、显示骨架屏。
- 首次请求结束后：
  无论成功还是失败，都将 `hasLoadedOnce` 标记为 `true`。
- 首次请求成功后：
  左侧切换为真实列表。
- 首次请求失败后：
  保持现有错误展示逻辑，不再重复展示首次加载动画。
- 后续切换榜单或输入搜索关键字时：
  沿用现有小型按钮 loading，不再回到大加载态。

这样可以保证“首次进入有明确引导，后续操作反馈更紧凑”。

### 5. 容器与布局边界

本次尽量不改通用 `ListPanel` 的数据结构判断逻辑。

商店页在传给 `ListPanel` 的默认插槽区域外层增加一次条件分支：

- `loading && !hasLoadedOnce` 时，渲染通用加载组件。
- 其他情况交给现有列表或空状态逻辑处理。

这样改动范围集中在商店页，通用组件只负责展示，不耦合具体业务条件。

### 6. 测试方案

前端测试先补到 `src/__tests__/storeView.test.ts`。

新增验证点：

- 首次挂载并且请求未完成时，左侧展示通用加载动画和骨架屏。
- 首次请求完成后，加载组件消失，真实列表出现。
- 后续切换榜单时，不再展示首次加载组件。

如通用组件逻辑有明显分支，可以补一个小型组件测试，确认骨架条数和样式类按 props 生效。

### 7. 验证方案

实现后执行：

- `npm test -- src/__tests__/storeView.test.ts`
- `npm run build`

手动检查：

- 首次进入商店页时，左侧只在列表内容区显示 logo 动画和骨架屏。
- 搜索栏和榜单切换控件保持可见。
- 首次加载完成后，列表正常显示。
- 后续切换榜单和搜索时，只出现现有小转圈。
- 组件样式在当前主题下没有突兀边框、空白或抖动。

## 验收标准

- 商店页首次进入时，左侧列表内容区出现基于当前 logo 的 Lottie 加载动画。
- 加载动画下方同时显示轻量骨架屏。
- 动画不包含额外文案。
- 搜索栏和榜单切换控件在首次加载期间保持可见。
- 首次加载结束后，大加载态消失，后续搜索和榜单切换不再重复出现。
- 新增的加载动画能力以通用组件形式落地，可供其他页面复用。
